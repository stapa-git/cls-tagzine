# CLS TAG ZINE（非公式） — ハッシュタグ・ボード（プロトタイプ）

> CLS高知（コミュニティリーダーズサミット in 高知）で使うことを想定した、**非公式**のファンメイド・プロトタイプです。公式ツールではありません。

X のハッシュタグ投稿を、カードとして切り貼りして遊ぶ Web アプリです。
**X API は使いません。** 投稿URLを貼り付けると、X の公式埋め込み（oEmbed / widgets.js）で本文・写真を表示します。

## できること

| 画面 | 内容 |
|---|---|
| ボード | 石垣状に並んだカード。並べ替え・シャッフル・本文や名前での絞り込み |
| ピックアップ | ★ を付けたカードの一覧。「一本釣りで1枚ひく」で、糸を垂らしてカードを釣り上げる演出 |
| タイムライン | 日ごとの投稿数の棒グラフと、時系列の並び。「▶ 時系列で再生」で1枚ずつ登場 |
| つながり | 本文の @メンション から「だれが だれに 触れているか」のネットワーク図（ドラッグ可、クリックでその人の投稿へ） |

- 期間の絞り込みは、投稿ID（Snowflake）から日時を計算して行うので通信なしで動きます
- 本文に指定のハッシュタグが入っていない投稿は自動で隠れます
- 写真・動画は ◎ ボタン（またはカードの「写真あり」）で公式埋め込みとして表示します
- 「共有リンク」で、ハッシュタグ・期間・URL・ピックアップをまとめたリンクを作れます（本文は含みません）
- 「書き出し／読み込み」で JSON に保存できます（URL とピックアップのみ）
- データはブラウザ（localStorage）に保存されます。サーバーはありません

### そのほかの機能

- **ロゴを押すと、文字がはねて鰹が飛び越えます**（ロゴの下にも案内ラベルがあります）
- **タグ・期間ボタン**：#CLS高知 / #きっかけはCLS / #CLSごはん / #CLS高知初参加、イベント当日の期間を1回押すだけで入力
- **スクリーンモード**：会場のプロジェクター向け。全画面でカードを1枚ずつ大きく自動表示（8秒ごと）。ピックアップ／すべて／新着順／ランダムを選べ、「公式表示」にすると写真つきで映します。キー操作：← → で前後、スペースで一時停止、Esc で終了
- **大量の投稿でも軽い**：本文はカードが画面に近づいたときに読み込み、ボードは120枚ずつ並べます。つながり図を全員分描くときは「本文を全部読み込む」

### タグ・期間ボタンの変え方

`app.js` の先頭にある `PRESETS` を書き換えます。

```js
const PRESETS = {
  defaultTag: 'CLS高知',
  tags: ['CLS高知', 'きっかけはCLS', 'CLSごはん', 'CLS高知初参加'],
  // date：開催日、around：前後に含める日数（7 なら開催日の前後1週間）
  periods: [
    { label: 'on 東京（2026/10/3）', date: '2026-10-03', around: 7 },
    { label: '2026初鰹編（2026/5/16）', date: '2026-05-16', around: 7 }
  ]
};
```

次の戻り鰹編の日程が決まったら、`periods` の先頭に1行足してください。前後の日数を変えたいときは `around` の数字を変えます（期間ボタンにマウスを乗せると、実際の期間が表示されます）。

### おすすめボード（あらかじめURLを入れておく）

`preset.json` に URL のリストを入れておくと、**はじめてアプリを開いた人には、自動でそのボードが表示されます**。

1. アプリでURLを貼ってボードを作る（★のピックアップも入ります）
2. 「書き出し」で保存したファイルの名前を `preset.json` に変えて、リポジトリの `preset.json` と置き換える
3. GitHub Desktop でコミット → Push

- すでに自分のボードがある人の画面は上書きしません。「おすすめボード」ボタンで追加できます
- `posts` が空のあいだは、何も起きません（ボタンも出ません）
- `index.html` をパソコンで直接開いたときは読み込めません（GitHub Pages など、公開したURLでだけ動きます）
- 保存されるのは URL・期間・ピックアップだけで、投稿の本文は含みません

## 投稿URLの効率的な集め方

1. ハッシュタグと期間を入れて **「① Xで検索をひらく」** を押す
   - `#タグ since:開始日 until:終了日の翌日 -filter:retweets`（写真つきだけなら `filter:images`）で、「最新」タブが開きます
2. 集め方は2通り
   - **A：1件ずつ** 共有ボタン →「リンクをコピー」→ アプリの「② 投稿URLを追加」に貼る（何件か貯めてからまとめて貼ってもOK。入力欄以外の場所に貼り付けても追加されます）
   - **B：まとめて** 「集め方ガイド」にある **CLS TAG ZINE コレクター** をブックマークバーにドラッグして登録 → X の検索結果ページでクリック → 自分でスクロールすると、表示された投稿URLが右下のカウンターに貯まる → カウンターをクリックしてコピー → アプリに貼る
3. 検索のコツ
   - `min_faves:10`（いいね10以上）を足すと、反応の多い投稿だけになります
   - 期間外・別タグのURLが混ざっても、アプリ側で自動的に絞り込まれます

> コレクターは画面に表示された投稿のリンクを拾うだけで、自動スクロールや自動取得はしません。必要な分だけ使ってください。

## 動かし方

- **ローカル**：`index.html` をブラウザで開くだけ（ビルド不要、インストール不要）
- **GitHub Pages で公開**
  1. GitHub で新しいリポジトリを作り、このフォルダの中身をすべて（`fonts` フォルダごと）アップロード。ブラウザからのアップロードは1回100ファイルまでなので、`fonts/files` は何回かに分けるか、GitHub Desktop や git コマンドを使ってください
  2. リポジトリの **Settings → Pages → Build and deployment** で Source を「Deploy from a branch」、Branch を `main` / `/(root)` にして Save
  3. 1〜2分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

## ファイル構成

```
index.html   画面の骨組み
style.css    見た目とアニメーション
app.js       すべての動き（外部ライブラリなし）
preset.json  おすすめボードのURLリスト（空のままでもOK）
fonts/       同梱フォント（fonts.css と、文字範囲ごとに分割した woff2 ファイル）
.nojekyll    GitHub Pages の変換を止めるための空ファイル
```

## フォント

- 見出し：Dela Gothic One、本文：M PLUS Rounded 1c（どちらも SIL Open Font License 1.1。ライセンス文は `fonts/` 内）
- Google Fonts と同じフォントを Fontsource 版で同梱しています。文字の範囲ごとにファイルが分かれていて、画面に出た文字の分だけ読み込まれます。外部への通信は不要です

## 注意

- 表示は X の公式埋め込みに依存します。広告ブロッカーで `platform.twitter.com` / `publish.twitter.com` が止められていると、本文や写真が出ません
- 削除・非公開になった投稿は表示できません
- 投稿本文をリポジトリやファイルに保存して再配布しないでください（このアプリは URL だけを保存し、本文は毎回 X から表示します）
- 「デモで試す」は架空のユーザー・投稿です
